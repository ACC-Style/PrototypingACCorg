## Slot length — estimate from the UI

Use `(Max: N chars)` on the grouped slot line — not a pattern link. **Do not** default every headline to 80 and every body to 150. Look at type size, column width, and how many lines the slot shows. Current copy is a floor with modest headroom, not a universal cap. Omit Max on long-form (letters, FAQ answers, mission paragraphs).

Arches `Sub.Placeholder.Text` sizes (20 / 30 / 40 / 60 / 80 / 100 / 150 / 200 / 250) are a nearby number, not a dump onto every slot.

| UI element | Typical Max | Why |
|------------|-------------|-----|
| Eyebrow / kicker | 24 | One short line, small type |
| Button / CTA label | 24–32 | Button width; longer shade CTAs toward 32 |
| Aside heading (narrow column) | 28–36 | Sidebar title |
| Display H1 / roadblock section name | 40 | Huge type; wraps poorly |
| Page H1 beside a micro-hero CTA | 40–50 | One line next to a button |
| Page H1 (title treatment, may wrap) | 50–60 | Page name, not a sentence |
| Band / page-break / roadblock H2 | 40–55 | Punchy one-line headline |
| Card / panel title | 40–50 | Card header, 1–2 lines |
| Subheader (under an H1) | 60–80 | Supporting line(s), not a paragraph |
| Overlay / teaser (2 lines) | 120–140 | Under a display title or in a hero overlay |
| Roadblock / join-band body | 120–160 | 2–3 short sentences in a card or band |
| Card body | 140–180 | 2–3 lines on a card |
| Intro / feature paragraph | 250–400 | Wide column, a short paragraph |
| Meta Title / Meta Description | 80 / 150 | SEO snippet, not on-page UI |
